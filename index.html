antigravity-starter

One-command graph-first workspace bootstrapper for Claude Code

Run one command and get a graph-first, rules-enforced development environment. antigravity-starter sets up a Claude Code workspace powered by graphify — your codebase, docs and papers become a queryable knowledge graph, built with tree-sitter AST extraction across 13 languages and semantic analysis. It runs 100% locally: no server, no authentication, no API keys.
